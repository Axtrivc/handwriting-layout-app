# 清除字迹：实现与回归验证

推荐照片使用「预览扫描 → 查看原图/效果 → 应用扫描 → 框选 → 预览清除 → 应用清除」。
原始扫描稿仍可直接框选清除，无需重复增强。
只有应用时才写入项目和撤销记录。切换页面、更换图片、加载项目后，旧清除请求的结果不再应用。
背景处理历史保留最近 10 次，扫描和清除按顺序逐步撤销；更换底图时清空该页历史。
扫描操作随工程 JSON 保存，旧工程没有操作类型时仍按清除历史读取。
精细画笔选区以原图像素坐标保存路径和粗细，旧工程可省略 `strokes` 字段。

## 精细选择与操作恢复

- 大图自动适合窗口，100% / 放大 / 缩小仅影响视图。编辑画布按窗口尺寸分配，避免在高分屏上创建整张照片四倍像素的交互画布。
- 矩形可调整位置和大小；精细画笔只清除实际路径，路径外接矩形内的其他内容不会因此被清除。单击形成圆点，支持撤销上一笔选区。
- 路径、圆头及膨胀后的擦除掩膜均限制在选区和图片边界内；透明通道保持不变。
- 等待中可以「取消处理」，保留原图和选区供重试。前端中止 HTTP 等待并丢弃过期结果；已经开始的后端图像计算不承诺立即停下。
- 预览、应用、撤销、取消和错误信息固定在左栏底部，不受参数区域滚动影响。

## 方向与扫描增强

- 所有后端图片入口先应用 EXIF 方向（含旋转、镜像），与浏览器显示尺寸及选区坐标统一，再清除该方向标记，避免再次旋转。
- 除 EXIF 归一化外，扫描默认开启「自动校正倾斜」。在约 ±12° 内依据文字行投影寻找清晰峰值，要求上下两部分均有支持；空白、稀疏、单斜线及证据不足的页面保持原方向。未实现无 EXIF 的 90° 内容方向识别、无参考透视或曲面矫正。
- `/prepare-scan` 先估计纸面光照、压低阴影，再输出灰度或自适应二值黑白 PNG。校正用旋转与等比缩放把完整页面放入原尺寸画布，边界不裁掉；会有重采样和留白。估角使用降采样图，实际输出在原尺寸上生成。旧 API 调用不传 `deskew` 时保持原行为。
- 校正预览同步变换文字图层的位置、字号、字距、模糊量和旋转；应用时更新文档及该页文本撤销/重做快照，撤销扫描时逆变换。其他页的撤销历史不变。预览期间锁定文字编辑，仍可平移、缩放和比较原图。
- 与当前画布对齐的彩色源随扫描历史保存，避免转正后仍使用旧坐标检测红蓝笔。工程导入验证变换字段与彩色图像资源。
- 黑白化前使用保边滤波抑制纸纹，滤波和阈值邻域随照片尺寸调整；标准模式提高背景与笔迹的对比要求，避免把纸张纤维、压缩噪声和较淡的背面透字变成黑点。保留原始像素尺寸，不用删除小连通块的方式去噪，以免误删句号、字母上的点和细线。
- 默认黑白模式适合白纸试卷擦除。「保留浅字」更敏感，但可能带入纸面噪声；「去噪更强」可能损失浅字。灰度模式保留更多明暗层次。
- 转黑白前后的印刷字、标点、细线必须先对比预览。该步骤不区分手写和印刷，也不恢复被笔迹遮住的原文。
- 前端拒绝尺寸与画布不一致的处理结果，保留当前背景。更新本地代码后需重启后端；旧版本已经错误旋转的结果建议从原始照片重新处理。

## 原卷对照修复

「原卷对照修复」接收同一页、同一版本的未填写原卷 PNG/JPG。使用 ORB 特征、比例筛选和 RANSAC 单应性对齐，再检查匹配数量/比例、空间分布、页面形状、覆盖范围及原文笔画支持。对齐不足时返回错误，保留原图。支持拍摄中的一定旋转、透视与分辨率差异，但不保证任意照片都能对齐。

通过检查后，在有效覆盖范围内使用参考原卷的实际像素替换当前背景；因此能去除黑色填写与批改，并恢复参考中确实存在的印刷内容。范围外像素与当前 alpha 保留，用户新建的文字对象保留。它不是逐笔语义分割，也不是根据上下文生成遮挡文字。部分未覆盖边缘仍可能留有批改，需要检查预览。

相似版本的个别文字差异不能仅靠匹配分数可靠排除，必须使用同一版本并核对题目与页码；不能把“对齐成功”当成版本一致性认证。应用后可撤销；恢复后的背景替代旧的辅助彩色源，避免后续自动颜色清除又引用旧批改图。

## 选区清除算法

- 使用局部纸张背景估计与逐颜色通道的对比度检测，替代固定灰度 <100 的黑字阈值。
- 提供轻柔、标准、加强三档；可关闭横线保留。
- 横线恢复要求选区左右两侧均有可靠证据，表格竖线要求上下两侧有证据；虚线按原图坐标估计周期，避免镜像复制邻近内容。
- 仅替换选区内检测到的笔画像素；选区外和 alpha 通道保持不变。
- API 始终返回 PNG，避免对 JPEG 扫描稿重复有损编码。`changed=false` 表示未检测到可清除内容。
- 越界区域真正裁剪；完全在图外的区域不会修改边缘像素。
- 对黑白扫描版，检测到的笔画像素恢复为白色纸底，不从相邻黑字插值出灰色涂抹；横线仍需要双侧证据。

这仍是针对纸面扫描稿的传统图像修复，不保证复杂照片、粗涂抹、倾斜/弯曲线条或严重阴影的无痕恢复。
合成样本不能替代用户真实扫描稿验收。先预览，检查细节后应用。
